# fase_1.md - Setup Base del Proyecto

## Objetivo de esta fase
Crear el proyecto Flutter desde cero, configurar todas las dependencias necesarias, establecer la estructura de carpetas definitiva e inicializar la base de datos con Drift.

Al finalizar esta fase, la app debe:
- Compilar sin errores en Android
- Mostrar una pantalla de inicio simple (scaffold vacio con titulo)
- Tener la base de datos Drift configurada y lista
- Tener Provider configurado en el arbol de widgets

**No se implementa ninguna funcionalidad de negocio en esta fase.**
